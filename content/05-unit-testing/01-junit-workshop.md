# JUnit Workshop

## Workshop Overview

This workshop covers unit testing fundamentals using JUnit, a popular testing framework for Java applications. You will learn how to write effective unit tests, understand test-driven development (TDD) principles, and integrate testing into your DevSecOps pipeline.

## Workshop Materials

Download the complete workshop document with step-by-step instructions, code examples, and screenshots:

[Download JUnit Workshop Document (DOCX)](/docs/S-DSOEA-Testing%20Tools%20Workshop%20-%20JUnit.docx)

## Key Topics Covered

- **Introduction to Unit Testing**: Understanding the importance of testing in software development
- **JUnit Framework**: Setting up and configuring JUnit in your Java project
- **Writing Test Cases**: Creating effective test methods with assertions
- **Test Annotations**: Using @Test, @BeforeEach, @AfterEach, @BeforeAll, @AfterAll
- **Assertions**: assertEquals, assertTrue, assertFalse, assertNull, assertThrows
- **Test Suites**: Organizing and running multiple test classes
- **Mocking**: Introduction to mocking dependencies with Mockito
- **Code Coverage**: Measuring test coverage with JaCoCo
- **CI/CD Integration**: Running tests in GitHub Actions pipelines

## Prerequisites

- Java Development Kit (JDK) 11 or higher
- Maven or Gradle build tool
- IDE (IntelliJ IDEA, Eclipse, or VS Code with Java extensions)
- Basic understanding of Java programming
