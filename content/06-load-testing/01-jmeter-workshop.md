# JMeter Workshop

## Workshop Overview

This workshop covers performance and load testing using Apache JMeter, a powerful open-source tool for testing functional behavior and measuring performance. You will learn how to create test plans, simulate user loads, and analyze performance metrics.

## Workshop Materials

Download the complete workshop document with step-by-step instructions, configuration examples, and screenshots:

[Download JMeter Workshop Document (DOC)](/docs/S-DSOEA%20-%20TestingToolsWorkshop%20-%20JMeter.doc)

## Key Topics Covered

- **Introduction to Load Testing**: Understanding performance testing concepts
- **JMeter Installation**: Setting up Apache JMeter on your system
- **Test Plan Creation**: Building test plans with thread groups and samplers
- **HTTP Requests**: Configuring HTTP request samplers for web applications
- **Assertions**: Adding response assertions to validate results
- **Listeners**: Using listeners to collect and visualize test results
- **Parameterization**: Using CSV data sets for dynamic test data
- **Timers**: Adding think time and pacing to simulate realistic user behavior
- **Distributed Testing**: Running tests across multiple machines
- **Results Analysis**: Interpreting response times, throughput, and error rates

## Prerequisites

- Java Runtime Environment (JRE) 8 or higher
- Apache JMeter (latest version)
- Basic understanding of HTTP protocol
- A web application to test (provided in workshop)

## Getting Started

1. Download the workshop document above
2. Install Apache JMeter from https://jmeter.apache.org/
3. Follow along with the video tutorial
4. Complete the hands-on exercises
5. Submit your completed work in the Submission tab
